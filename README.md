# Ai Chat

دستیار هوش مصنوعی فارسی — یک اپلیکیشن وب قابل نصب (PWA).

## ساختار

| فایل | توضیح |
|---|---|
| `index.html` | کل اپ (HTML + CSS + JS در یک فایل) |
| `manifest.json` | تنظیمات نصب روی صفحه خانگی |
| `sw.js` | کار آفلاین و بارگذاری سریع |
| `icons/` | آیکون‌های اپ در اندازه‌های مختلف |

## انتشار

این مخزن به Cloudflare Pages وصل است.
هر تغییری که اینجا ذخیره شود، ظرف حدود یک دقیقه روی سایت منتشر می‌شود.

## امنیت

هیچ کلید API در این مخزن نیست. تمام درخواست‌ها از یک Cloudflare Worker
عبور می‌کنند که کلیدها را به‌صورت Secret نگه می‌دارد و سهمیه هر کاربر را
روی سرور محدود می‌کند.
